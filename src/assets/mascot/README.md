# Tiny Khushi's drawings

Drop exported frames here, named `pose-expression`:

    sit-judging.webp   peek-shocked.webp   stand-proud.webp   wave-happy.webp

They're picked up automatically (no code changes). Optional blink frames:
`sit-neutral-blink.webp`. Check them at /mascot while running `npm run dev`.

Full list, canvas sizes and placement guides: ../../../docs/tiny-khushi-art-brief.md
